# 🏠 Airbnb Listings Analysis — Tableau

## 📌 Project Overview

This project analyses Airbnb listings data to explore pricing, availability, and listing patterns.

The analysis was developed using **Tableau** to transform the dataset into interactive visualisations and make key trends easier to understand.

## 🛠️ Tools & Technologies

* Tableau — Data visualisation and dashboard development
* Excel / CSV — Dataset
* GitHub — Project documentation and version control

## 📊 Tableau Analysis

The Tableau workbook explores Airbnb listing data through visual analysis of factors such as:

* Listing prices
* Availability
* Property/listing characteristics
* Geographic and market patterns
* Distribution of listings across different categories

The visualisations help identify patterns and trends within the Airbnb market.

## 💡 Key Insights

The analysis provides a visual overview of Airbnb listings and allows users to explore differences in pricing, availability, and listing characteristics.

Interactive Tableau visualisations make it easier to compare listings and identify patterns within the dataset.
